# 🎵 Tucus Music Player

[![Windows Support](https://img.shields.io/badge/Platform-Windows-blue.svg?logo=windows)](./tucus-setup.exe?raw=true)
[![Tauri v2](https://img.shields.io/badge/Framework-Tauri%20v2-orange.svg?logo=tauri)](https://tauri.app)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](./LICENSE)

Современный, производительный и стильный музыкальный плеер для Windows с поддержкой **Яндекс Музыки**, **VK Музыки**, **SoundCloud**, релизов **Риса за Творчество (RZT)**, интерактивной визуализацией **Wave/Aurora**, **Эквалайзером**, караоке-текстами и **Discord Rich Presence**.

---

## 🚀 Инструкция по установке (Установка в 1 клик)

Выберите наиболее удобный для вас вариант запуска:

### 📦 Вариант 1: Автоматический установщик (Рекомендуется)
Полная установка с созданием ярлыков в меню «Пуск» и на Рабочем столе, а также автоматическим обновлением.

1. **[📥 Скачать Установщик Windows (tucus-setup.exe)](./tucus-setup.exe?raw=true)**
2. Запустите скачанный файл `tucus-setup.exe`.
3. Следуйте инструкциям мастера установки (занимает менее 10 секунд).
4. Запустите **Tucus Music Player** через ярлык на Рабочем столе.

---

### 💼 Вариант 2: Портативная версия (Portable)
Работает сразу без установки. Отлично подходит для запуска с флешки или использования без прав администратора.

1. **[📥 Скачать Портативную версию (tucus-portable.exe)](./tucus-portable.exe?raw=true)**
2. Поместите файл `tucus-portable.exe` в любую удобную папку.
3. Двойным кликом запустите приложение — оно сразу готово к работе.

---

> [!TIP]
> **Предупреждение Windows SmartScreen (Защитник Windows):**  
> Так как приложение распространяется напрямую с GitHub без платного цифрового сертификата, Windows может показать окно *"Защитник Windows предотвратил запуск нераспознанного приложения"*.  
> **Чтобы запустить:** Нажмите кнопку **«Подробнее»** (More info) ➔ затем **«Выполнить в любом случае»** (Run anyway).

## ✨ Основные возможности

* 🌟 **Лента Релизов RZT**: 100% актуальная лента свежих релизов с сайта *risazatvorchestvo.com* с возможностью мгновенного прослушивания через Яндекс Музыку.
* 🎙 **Карточки и Профили Артистов**: Дискография, HD-обложки, метаданные и статистика подписчиков (Spotify / SoundCloud / Yandex).
* 👥 **Мульти-авторский выбор**: Удобное меню выбора конкретного исполнителя при клике на треки с несколькими авторами.
* 🎮 **Discord Rich Presence**: Отображение обложки, названия трека, исполнителя и живого прогресс-бара в вашем профиле Discord (*"Слушает музыку в Tucus"*).
* 🎤 **Синхронизированные тексты песен**: Встроенный поиск текста с караоке-подсветкой и интерактивной волной.
* 🎨 **Liquid Glass & Aurora UI**: Элегантный стеклянный интерфейс с адаптивной цветовой гаммой под обложку текущего трека.
* 🎚 **Аудио-эффекты**: Встроенный 10-полосный эквалайзер и визуализатор аудио-частот.

## 🛠 Сборка из исходного кода (Для разработчиков)

Если вы хотите собрать приложение самостоятельно из исходников:

### Предварительные требования
* [Node.js](https://nodejs.org/) (v18+)
* [Rust](https://www.rust-lang.org/) (с поддержкой `x86_64-pc-windows-msvc`)

### Шаги для сборки:
```bash
# 1. Клонировать репозиторий
git clone https://github.com/twofolp/tucus-playes.git
cd tucus-playes

# 2. Установить зависимости Node.js
npm install

# 3. Запустить в режиме разработки (Dev mode)
npm run tauri dev

# 4. Собрать готовый инсталлятор и exe
npm run tauri build
```

Исполняемые файлы после сборки будут находиться в папке `src-tauri/target/release/bundle/nsis/`.
